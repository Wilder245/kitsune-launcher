# Kitsune Launcher

**ES** — Launcher personalizado de Minecraft: Java Edition de *Red Kitsune's*. Inicia sesión con tu cuenta de Microsoft, descarga el juego directamente desde los servidores de Mojang y lo lanza con Fabric y mods de rendimiento (Sodium, Lithium, FerriteCore…). Disponible desde la versión 1.20 hasta la más reciente; las versiones nuevas aparecen automáticamente.

**EN** — Custom launcher for Minecraft: Java Edition by *Red Kitsune's*. Players sign in with their own Microsoft account (OAuth 2.0 device code flow); the launcher downloads the game, libraries, assets and the official Mojang Java runtime from Mojang's servers, installs Fabric and performance mods from Modrinth, and starts the game. Only accounts that own Minecraft: Java Edition are supported.

## Características / Features
- Todas las versiones release desde 1.20, incluidas las nuevas / All releases from 1.20, new ones appear automatically
- Fabric + mods de rendimiento desde Modrinth / Fabric + performance mods from Modrinth
- RAM configurable, resolución predeterminada, ventana o pantalla completa / Configurable RAM and display mode
- Refresh token cifrado con el almacén seguro del sistema / Refresh token encrypted with the OS secure storage

## Uso / Usage
```bash
npm install
npm start
```
Requiere Node.js 20+ y una cuenta con Minecraft: Java Edition.

## Privacidad / Privacy
No se envían credenciales a ningún servidor propio: solo a Microsoft, Xbox Live y Mojang. / No credentials are sent to any server other than Microsoft, Xbox Live and Mojang.
